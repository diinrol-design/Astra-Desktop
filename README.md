# Companion Desktop

**Персональный ИИ-компаньон для Windows с локальными и облачными моделями.**

Companion объединяет общение с ИИ, память, интернет-поиск, работу с файлами, изображениями и кодом, а также инструменты и расширяемую систему модулей в одном приложении.

## Companion Desktop

![Companion Desktop](2fc130fe-6a49-4fa2-a1ab-65b5b48fde48.png)

## Основные возможности

- локальные GGUF-модели через встроенный движок на базе llama.cpp — Ollama не требуется;
- подключение облачных моделей ИИ;
- долговременная память и обучение;
- поиск и исследование информации в интернете, включая отзывы, форумы, изображения и товары;
- работа с документами, архивами и изображениями;
- отдельные возможности для программирования и работы с проектами;
- MCP для подключения внешних инструментов и сервисов;
- голосовые и визуальные возможности через модули;
- управление компьютером через устанавливаемые модули и систему разрешений;
- Companion Hub для поиска и загрузки локальных моделей;
- расширяемая система модулей;
- встроенные обновления и диагностика.

## Companion Hub

Встроенный каталог локальных GGUF-моделей. Можно найти подходящую модель, посмотреть её характеристики, варианты квантования и требования к памяти, а затем скачать её прямо из Companion.

![Companion Hub](13ea9ff2-90af-42aa-b25a-6d363ced8cda.png)

## Локально или в облаке

Companion может работать как с локальными моделями на компьютере пользователя, так и с подключаемыми облачными ИИ. Локальные модели и дополнительные модули устанавливаются отдельно по мере необходимости.

## Системные требования

- Windows 10 / Windows 11, 64-bit;
- объём оперативной памяти для локального ИИ зависит от выбранной модели;
- для облачных моделей и интернет-функций требуется подключение к интернету.
