# Astra Desktop

**Персональный ИИ-ассистент для Windows**

Astra объединяет локальные и облачные модели ИИ, долговременную память, интернет-поиск, работу с файлами, кодом, изображениями, голосом и дополнительными модулями в одном приложении.

## Возможности

- Локальные GGUF-модели
- Работа локальных моделей без обязательной установки Ollama
- Поддержка облачных моделей ИИ
- Долговременная память
- Использование разных моделей для разных задач
- Поиск информации в интернете
- Работа с файлами и изображениями
- Работа с кодом
- Голосовые возможности
- Устанавливаемые модули

## Локальный ИИ

Astra может запускать GGUF-модели непосредственно на компьютере пользователя через встроенный движок.

Ollama для работы локальных моделей не требуется.

Модели можно устанавливать непосредственно через Astra.

## Системные требования

- Windows 10 / Windows 11
- 64-разрядная система
- Требования к оперативной памяти зависят от выбранной локальной модели
