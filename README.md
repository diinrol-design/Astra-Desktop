# Companion Desktop

**Персональный ИИ-компаньон для Windows: локальные и облачные модели, память, интернет, MCP, работа с файлами и управление ПК.**

Companion Desktop — настольный ИИ-компаньон для Windows, который объединяет обычный чат, локальные GGUF-модели, облачные ИИ, долговременную память, интернет-исследования, работу с документами и изображениями, кодинг, MCP-инструменты и расширяемую систему модулей.

## Интерфейс Companion

Современный тёмный интерфейс с чатами, памятью, личностью, мониторингом, моделями, Hub, модулями и настройками.

![Companion Desktop](13ea9ff2-90af-42aa-b25a-6d363ced8cda.png)

## Companion Hub

Companion Hub — встроенный каталог локальных GGUF-моделей с Hugging Face. Он показывает возможности модели, доступные варианты квантования, размеры файлов и примерные требования к оперативной памяти. Модели можно скачать и выбрать прямо из Companion.

## Что умеет Companion

### Локальные и облачные модели

- запуск GGUF-моделей через встроенный движок на базе llama.cpp;
- Ollama не требуется для основной работы локальных моделей;
- выбор локальной или облачной модели;
- поддержка подключаемых облачных провайдеров через модуль Remote AI;
- отдельная маршрутизация обычного диалога, интернет-запросов, кодинга, Vision и инструментов.

### Память и обучение

- долговременная память о фактах, предпочтениях и важных событиях;
- обучение по взаимодействию с пользователем и исправлениям;
- отдельный главный переключатель «Использовать память и обучение»;
- история текущего разговора работает независимо от долговременной памяти;
- интернет-поиск имеет собственный слой обучения: Companion запоминает удачные формулировки запросов, полезные источники и неудачные маршруты поиска, не смешивая эти данные с личной памятью.

### Интернет и исследования

- обычный поиск актуальной информации в интернете;
- ранжирование более надёжных и официальных источников;
- поиск официальной документации для задач программирования;
- отдельный режим «что думают люди»: форумы, отзывы, обсуждения и мнения пользователей;
- поиск изображений с галереей нескольких вариантов;
- товарный поиск с карточками, изображениями, магазинами, ценами, наличием, рейтингами и отзывами, когда эти данные реально найдены в источнике;
- цены и наличие не придумываются моделью: они извлекаются из поисковой выдачи или страниц магазинов.

### Файлы, документы и изображения

- вложения передаются в Companion прямо из чата;
- извлечение и анализ содержимого документов и архивов;
- работа с PDF, DOCX, текстовыми и другими поддерживаемыми форматами;
- отдельная маршрутизация вложений, чтобы текст документа не воспринимался как команда управления ПК;
- анализ изображений через Vision-слой и подключаемый модуль зрения;
- поддержка мультимодальных запросов при использовании подходящей модели.

### Кодинг и проекты

- отдельный Code Engine для задач программирования;
- анализ структуры проекта и исходного кода;
- работа с проектными архивами;
- планирование изменений, генерация и применение исправлений;
- проверки синтаксиса, структуры и целостности изменений;
- поиск официальной документации с резервными интернет-провайдерами, если первый поиск не дал подтверждённого источника.

### MCP — Model Context Protocol

Companion имеет встроенную MCP-систему версии 2.x для подключения внешних инструментов и источников данных.

Поддерживаются:

- локальные MCP-серверы через stdio;
- удалённые серверы через Streamable HTTP;
- MCP tools, resources, resource templates и prompts;
- официальный MCP Registry и установка совместимых серверов;
- безопасный автоматический вызов read-only инструментов из обычного чата;
- ручные разрешения для чувствительных и опасных действий;
- OAuth для удалённых MCP-серверов;
- защищённое хранение токенов и API-ключей в Windows через DPAPI;
- добавление MCP-ресурсов в чат или одноразовый скрытый контекст следующего запроса.

### Управление Windows

Через устанавливаемый модуль PC Control Companion может выполнять разрешённые действия на компьютере:

- запускать приложения;
- находить, активировать, сворачивать и разворачивать окна;
- вводить текст и нажимать клавиши;
- управлять мышью и прокруткой;
- работать с файлами и папками в рамках разрешений;
- выполнять безопасные системные действия, включая отдельные команды питания и управления Windows;
- выполнять составные сценарии вроде «открой программу и введи текст».

PC Control использует систему разрешений и безопасные списки, а не генерирует произвольные shell-команды для каждого действия.

### Голос и Vision

В Companion присутствует единый голосовой слой для интеграции голосовых модулей с чатом: распознавание речи, потоковая озвучка ответа, управление микрофоном и возможность прерывать озвучивание голосом при установленном соответствующем модуле.

Vision подключается через систему модулей и может использовать камеру, анализ изображений и визуальную память при наличии разрешений и совместимой модели.

### Модули и безопасность

- дополнительные возможности устанавливаются отдельно и не обязаны входить в основной установщик;
- каталог модулей может загружаться из Companion Update Network с локальным резервом;
- ZIP-пакеты модулей проверяются по SHA-256 перед установкой;
- у модулей есть отдельные разрешения на системное управление, камеру, микрофон, данные и другие возможности;
- встроенный Capability Registry объединяет разрешённые возможности модулей и MCP.

### Обновления и диагностика

- встроенная проверка обновлений Companion;
- отдельная программа обновления;
- каталог модулей;
- система журналов и диагностики;
- отправка багрепортов с локальным резервным вариантом при недоступности сервера.

## Системные требования

- Windows 10 или Windows 11;
- 64-разрядная система;
- для локальных моделей объём ОЗУ зависит от выбранной GGUF-модели и квантования;
- для облачных моделей, интернет-функций, Hugging Face, MCP Registry и сетевых модулей требуется подключение к интернету.
